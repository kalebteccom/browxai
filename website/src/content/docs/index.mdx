<div class="browx-section not-content">
  <h2 class="browx-section-title">What you get</h2>
  <div class="browx-section-sub">
    browxai owns its transport to all eight engines.
  </div>

<div class="browx-grid">
  <div class="browx-card">
    <span class="browx-card-mark">Surface</span>
    <h3>Token-efficient</h3>
    <div class="browx-card-text">
      <code>snapshot()</code> returns a scoped, budgeted tree. <code>find()</code> returns ranked
      candidates.
    </div>
  </div>
  <div class="browx-card">
    <span class="browx-card-mark">Native</span>
    <h3>Native apps, same tools</h3>
    <div class="browx-card-text">
      <code>native-device</code> lets the same tools drive Android emulator and iOS Simulator apps.
    </div>
  </div>
  <div class="browx-card">
    <span class="browx-card-mark">Host</span>
    <h3>Reaches past the tab</h3>
    <div class="browx-card-text">
      Host features such as the clipboard and workspace files start off.
    </div>
  </div>
  <div class="browx-card">
    <span class="browx-card-mark">Safety</span>
    <h3>Default capabilities</h3>
    <div class="browx-card-text">
      Arbitrary JS and response bodies start off. Every call has a hard deadline.
    </div>
  </div>
  <div class="browx-card">
    <span class="browx-card-mark">Clients</span>
    <h3>Model-agnostic</h3>
    <div class="browx-card-text">Any MCP client over stdio, plus a typed TypeScript SDK.</div>
  </div>
  <div class="browx-card">
    <span class="browx-card-mark">Sessions</span>
    <h3>Sessions and lifecycle</h3>
    <div class="browx-card-text">
      Sessions use the installed Google Chrome on one default profile per workspace.
    </div>
  </div>
</div>
